ADK in five ideas

The ten-minute demo, so nothing in Lab 4 surprises you.

  1. An agent is a name, a model, an instruction and optional tools.
  2. A tool is a plain Python function. ADK reads its docstring to tell the model how to call it.
  3. sub_agents=[...] makes a team. Each child's description is its routing rule.
  4. The package exposes root_agent from agent.py.
  5. adk web serves a chat UI at localhost:8000 and traces every handoff and tool call.
support_triage/agent.py (shape)
from google.adk.agents import Agent

billing_agent = Agent(
    name="billing_agent",
    model="gemini-3.5-flash-lite",
    description="Handles invoice and charge questions.",
    instruction="Look the customer up, then call check_invoice.",
    tools=[check_invoice],
)

root_agent = Agent(
    name="triage_router",
    model="gemini-3.5-flash-lite",
    description="Routes support messages.",
    instruction="Do not answer yourself. Transfer to the right specialist.",
    sub_agents=[billing_agent],
)

Five timed labs

Every lab starts in the triage-workshop folder. Type each prompt into your coding agent. The rule for the whole session: no code until the design passes the gate.

1

Design with no code

0:1815 min/elephant-grow

Leave with decisions, not code. The skill refuses to write code and challenges your assumptions. Settle these five things before you stop:

  • Routing: which messages go where, and what happens when one fits two.
  • Tool contracts: inputs, outputs and the error case for each of four tools.
  • Severity rules for tickets.
  • Out of scope: at least two things you will not build.
  • Success checks: three messages and the exact routing you expect.
Prompt
/elephant-grow I want a local-only customer support triage system built with Google ADK (the google-adk package, already installed) in Python. A coordinator agent named triage_router routes each message to a billing, technical or escalation specialist, using ADK sub_agents. The code lives in a package called support_triage/ in the project root and exposes root_agent from agent.py, so it runs with adk web. Data is in data/customers.json and data/kb.json, tickets go to a local file, and nothing is deployed. Ask at most 5 questions at a time. Challenge my routing rules, my tool inputs and outputs, and how we will know it works.
Hard stop 0:33. Not finished? Go to Lab 2 with the five bullets you have.

Budget one

Your coding agent

agy signs in with your Google account and uses that account's Antigravity free allowance. It is thin, and published numbers disagree. Out of it? Take the checkpoint for that lab and follow along on screen.

Budget two

Your ADK app

The key in .env is used by the agents you build, and counts against that Google project's Gemini API free tier. Send messages a few seconds apart. See live limits at aistudio.google.com/rate-limit.

agy: command not found

The installer put the binary where your shell has not looked yet. Open a new terminal. If it is still missing, add ~/.local/bin (macOS, Linux) or %LOCALAPPDATA%\Antigravity (Windows) to your PATH.

Typing /elephant-grow does nothing

The skills are not in the folder your agent was started from. Run ls .agents/skills (or .claude/skills), expect seven folders, then restart the agent from the project root. If they are missing, run python install_skills.py.

adk web shows no agents

You started it from inside support_triage/. Run cd .. to the project root and start it again.

ModuleNotFoundError: google.adk

Your virtual environment is not active. Run source .venv/bin/activate (macOS, Linux) or .venv\Scripts\Activate.ps1 (Windows).

429 RESOURCE_EXHAUSTED from Gemini

You hit the per-minute or per-day free quota. Wait a minute and send fewer messages. If it says daily, change WORKSHOP_MODEL in .env to another model that AI Studio shows with quota.

A 429 with "limit: 0" means that model has no free quota for your key. Use a model your AI Studio rate-limit page lists as available.

404 model not found

The model name in .env has a typo or has been retired. Check the model list in AI Studio and fix WORKSHOP_MODEL.

403 PERMISSION_DENIED, project denied access

Google flagged or restricted the project. Create a key in a different project or account. The tech desk keeps spare keys.

Coding agent stalls, queues or says quota used

Your free Antigravity allowance is spent. Switch to the checkpoint for that lab, pair with a neighbour, and do not retry in a loop.

My laptop blocks the install script or Google sign-in

A corporate security policy is the usual cause. Pair with a neighbour for the day, or ask your IT team ahead of time.
